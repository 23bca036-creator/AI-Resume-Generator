# AI-Resume-Generator
AI Resume Generator is a full-stack web application that helps users create professional and ATS-friendly resumes using AI. It provides AI content suggestions, ATS analysis, live resume preview, multiple templates, and PDF/DOCX export. Built using Next.js, Node.js, Express.js, PostgreSQL, Supabase, Prisma, and Google Gemini API.
## About Project 

**AI Resume Generator Web Application** is a full-stack web application developed to help students, freshers, and professionals create professional and ATS-friendly resumes. The application simplifies the resume-building process by combining a user-friendly resume editor with AI-powered content suggestions.

Users can create an account, enter their personal information, education, skills, projects, certifications, and experience, and generate a structured resume. The application provides a **live preview**, allowing users to see changes while editing their resume.

###  Key Features

*  **User Authentication** – Secure registration and login using JWT.
*  **Resume Builder** – Add and edit personal details, education, skills, projects, experience, and certifications.
*  **AI Assistance** – Google Gemini AI helps generate professional summaries and improve resume content.
*  **ATS Analyzer** – Compares the resume with a job description, checks keywords, and provides improvement suggestions.
*  **Resume Import** – Extract information from an existing resume and organize it into different sections.
*  **Multiple Templates** – Choose professional resume designs according to user requirements.
*  **Live Preview** – View resume changes instantly while editing.
*  **PDF & DOCX Export** – Download the completed resume in commonly used formats.
*  **Multiple Resumes** – Create and manage different resumes for different job roles.
*  **Responsive Design** – Works across desktop, tablet, and mobile devices.

###  Technologies Used

**Frontend:** Next.js, JavaScript, Tailwind CSS, Framer Motion
**Backend:** Node.js, Express.js
**Database:** PostgreSQL, Supabase, Prisma ORM
**AI:** Google Gemini API
**Authentication:** JWT
**Tools:** Git, GitHub, VS Code, Postman

###  Project Objective

The main objective of this project is to reduce the time and effort required to create a professional resume. By using AI-based content suggestions and ATS analysis, the application helps users customize their resumes according to different job requirements.
